# Synthetic Land Acquisition Dataset

This directory contains synthetic datasets generated specifically for training, validating, and testing the BhoomiSetu Land Acquisition Intelligence pipeline.

## Important Privacy and Compliance Notice

> **Synthetic Data Only:** The data generated and contained in this directory is 100% synthetically generated for prototype and decision-support research.
> - **NO** real citizen data, Aadhaar numbers, phone numbers, individual banking records, or personally identifiable information (PII) are used or stored.
> - Names, parcel IDs, and transactional values are simulated using deterministic pseudorandom generators to reflect realistic macro-distribution patterns under the Right to Fair Compensation and Transparency in Land Acquisition, Rehabilitation and Resettlement Act, 2013 (RFCTLARR Act).

## Files
- `generate_dataset.py`: Reproducible synthetic data generation script.
- `sample_land_acquisition.csv`: Pre-generated dataset generated by `generate_dataset.py` using random seed `42`.

## Regeneration
To regenerate the dataset, execute from the repository root or intelligence directory:
```bash
python data/generate_dataset.py
```
